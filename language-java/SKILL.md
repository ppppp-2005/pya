# Java/Spring 系统开发

使用这个技能处理 Java 系统，尤其是 Spring Boot 后端和毕业设计管理系统。

## 分层建议

- **Controller**：只处理请求参数、权限入口、响应包装；不要堆业务逻辑。
- **Service**：放核心业务、事务边界、状态流转、校验规则。
- **Repository/Mapper**：只负责数据访问。
- **DTO/VO**：隔离接口输入输出，避免直接暴露实体。
- **Entity**：表达数据库结构和核心字段，不承担复杂业务流程。

## 关键检查

- 事务是否放在正确的 Service 层。
- 异常是否统一处理，错误信息是否清楚。
- 参数校验是否完整，分页/排序/搜索是否有边界。
- 登录认证、角色权限、越权访问是否处理。
- SQL 是否存在注入风险，查询是否有索引和性能问题。
- 测试是否覆盖 Service 业务逻辑、Controller 接口和异常路径。

## 常见输出

- 项目结构建议
- 数据库表设计
- REST API 设计
- Service 实现计划
- 统一响应和异常处理方案
- Spring Boot 毕业设计论文可用描述

## 编码要求

- 遵守项目已有包名、命名和注解风格。
- 不随意引入复杂框架。
- 对新增接口给出请求参数、返回示例和错误场景。
