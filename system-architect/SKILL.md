# 系统架构设计

使用这个技能把想法变成可实现、可写论文、可落地的系统方案。

## 设计步骤

1. **明确系统边界**
   - 用户角色、核心场景、输入输出、权限边界、运行平台。
   - 区分必须功能和可选功能。

2. **选择架构**
   - 小型系统优先简单分层：表现层、业务层、数据层。
   - Web 系统明确前端、后端、数据库、认证、文件存储、部署。
   - C++ 系统明确模块、类边界、资源管理、线程模型和构建方式。
   - Java 系统明确 Controller、Service、Repository、DTO、Entity。
   - Python 系统明确路由、服务、模型、任务、配置和依赖管理。

3. **设计数据**
   - 给出核心实体、字段、关系、索引、约束。
   - 说明关键状态流转和数据一致性规则。
   - 数据库设计要能转成论文中的 E-R 图和表结构说明。

4. **设计接口**
   - 给出 API、函数或模块接口。
   - 说明请求参数、返回值、错误码、权限要求。
   - 对外部依赖要说明失败策略和超时策略。

5. **规划实现**
   - 按最小可运行版本拆分阶段。
   - 每阶段列出要创建或修改的文件。
   - 给出测试策略和验收标准。

## 输出要求

- 方案必须具体到模块、数据表、接口和实现步骤。
- 如果有多种方案，推荐一个最适合当前规模的方案。
- 对毕业设计项目，额外给出可写进论文的“总体设计”和“详细设计”段落。
