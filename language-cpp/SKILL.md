# C++ 系统开发

使用这个技能处理 C++ 项目时，优先保证正确性、资源安全和可维护性。

## 关注点

- **构建**：检查 `CMakeLists.txt`、编译选项、依赖、头文件路径、目标划分。
- **资源管理**：优先 RAII、智能指针、值语义；避免裸 `new/delete`。
- **接口设计**：头文件只暴露必要接口，减少编译耦合。
- **类设计**：明确所有权、生命周期、不变量和线程安全。
- **错误处理**：根据项目风格选择异常、错误码或 `std::optional/std::expected` 类模式。
- **性能**：避免不必要拷贝；关注算法复杂度、容器选择、移动语义。
- **并发**：明确锁粒度、共享状态、死锁风险和数据竞争。
- **测试**：为核心算法、边界输入、异常路径和资源释放写测试。

## 编码建议

- 使用 `const`、引用和值语义表达意图。
- 优先标准库，避免自己实现常见容器或工具。
- 对跨平台代码，避免依赖平台特有行为，必要时隔离适配层。
- 修改前先理解调用方和对象生命周期。

## 输出要求

- 给出编译/运行/测试命令。
- 解释关键类和数据结构。
- 对内存、性能或并发风险明确标注。
